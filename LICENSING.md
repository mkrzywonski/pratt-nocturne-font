The full license and copyright notice are embedded in each font. A copy is
also included in the fonts directory so it travels with that folder.

scripts and the Nix build environment. The original font-design data embedded
in those scripts remains under OFL 1.1 as described above. MIT licensing of
the build machinery does not relicense the resulting fonts.
